# 外部执行器：用 Codex 等 agent 识别图纸

bidbench 把“看图识别”打包成任务包，任何能看图、能写文件的 agent 都能执行。适合想用自己的订阅额度或别家模型的场景。

> 想用 ChatGPT 订阅额度识别，现在不用手动交任务包了：`bidbench chatgpt login` 登录后 `bidbench recognize --executor codex`，
> 或者在工作台「识别」里选“ChatGPT 账号”（见 README 的“图纸识别”）。下面的手动方式适合其他 agent。

## 步骤

1. 生成任务包（会渲染页面图片和图签放大图）：

   ```bash
   bidbench tasks                    # 默认挑新页面；--scope weak / conflict / all 见 README
   ```

   输出类似 `recognition/tasks/20261011-180846`。

2. 把任务包目录交给 agent 的目标模式，目标可以直接这样写：

   ```text
   按 任务说明.md 完成本任务包的图纸识别。
   完成标准：manifest_in.json 里的每一页在 results/pages/ 下都有 <page_id>.json 和 <page_id>.md，
   每个 JSON 都通过 schema.json 校验，results/run_log.md 写明遇到的问题。
   不要修改 results/ 以外的文件。
   ```

3. 跑完后导入：

   ```bash
   bidbench import recognition/tasks/20261011-180846/results
   bidbench build
   ```

   没通过校验的文件不会导入，原因写在 `reports/识别结果导入问题.md`。修正后重新导入即可，已导入的页面会被新结果覆盖。

## 任务包里有什么

| 路径 | 内容 |
| --- | --- |
| `任务说明.md` | 给 agent 的完整识别要求和硬性规则 |
| `schema.json` | 输出格式，必须完全遵守 |
| `manifest_in.json` | 待识别页面清单，`source` 字段直接照抄进结果 |
| `pages/<page_id>.png` | 整页图片，约 150 dpi |
| `pages/<page_id>-titleblock.png` | 右下角图签区域放大图，约 300 dpi |
| `text/<page_id>.txt`、`text/<page_id>.json` | PDF 文字层全文，以及逐行文字和归一化位置 |
