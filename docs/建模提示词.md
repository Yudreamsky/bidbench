# 让 Codex 照图建模：建模的和检查的

开两个 Codex 对话，都接上 bidbench（工作台 AI 助手 → “接到 Codex”）。一个负责建模，一个负责检查。
检查的那个**单开一个对话**，不看建模的过程，只看建模交出来的依据清单和 bidbench，这样它不会顺着建模的思路犯同样的错。

做法要点：

1. **先定骨架**：轴网、标高、楼层先建，你确认了再建构件。骨架错了后面全错。
2. **每个构件都有出处**：建模的把每个构件依据的图号、版次、page_id、位置 bbox、读到的数值写进 `建模依据.json`，
   检查的用 `check_basis` 逐条对照现行图纸，没写出处的构件直接算不合格。
3. **一次一小块**：一层的一个专业，查过了再往下。
4. **不猜**：图上看不清、缺图、几张图对不上的，列成清单问你（可以直接写进答疑）。
5. **图纸升版以后**：把 `建模依据.json` 交给 `check_basis` 再核一遍，“要复核”的就是受影响的构件。

下面两段是第一句话的样子，把楼层、专业、建模软件换成你要的。在 Revit 里建模时同时接上 Revit MCP
（做法见 [MCP.md](MCP.md)“和 Revit MCP 一起用”），把“写 Dynamo 脚本”换成“用 Revit MCP 建”，
翻模用 bidbench 的 `cad_file` 拿 DXF，再交给 Revit MCP 的 `read_cad`、`cad_to_model`。

## 建模的 Codex

```text
你负责按图建模。图纸数据都在 bidbench 的工具里，只用现行版。

这次的范围：3 层结构（柱、梁、板）。

1. 用 find_sheets_for_task(floor="3F", discipline="结构") 找该看的图；missing（缺图）和 notices（变更单）先列给我。
2. 先只做骨架：轴网、本层和上下层标高。写出每条轴线、每个标高依据哪张图，交给我确认，确认前不要建构件。
3. 骨架确认后建构件。每个构件看主图的 get_sheet / get_page，“详见”的地方用 related_sheets 找到被指的图，
   用 locate(page_id, bbox) 回到原图那块地方读数值。
4. 每建一个构件，在工作文件夹的 建模依据.json 里记一条：
   {"element": "3F KL3 1~2/A 轴", "sheet": "结施-04", "rev": "C", "page_id": "...", "bbox": [x0, y0, x1, y1],
    "value": "350×700", "notices_applied": []}
   按变更单改过的构件，把变更单编号写进 notices_applied。
5. 模型写成 Dynamo 脚本（或 IFC / pyRevit），构件参数里写上依据的图号和版次。
6. 交付前自己先用 check_basis 核一遍 建模依据.json（一次最多 200 条），把“不合格”的改掉。
7. 看不清、缺图、几张图对不上的尺寸不要猜，列成“待确认”清单给我。
```

## 检查的 Codex（另开一个对话）

```text
你负责检查模型，不负责建模，也不改模型。图纸数据都在 bidbench 的工具里，只认现行版。

要检查的：工作文件夹里的 建模依据.json 和模型脚本，范围是 3 层结构。

1. 用 check_basis 核对 建模依据.json 全部条目（一次最多 200 条，分批），汇总“不合格”和“要复核”。
2. 对数：用 find_sheets_for_task(floor="3F", discipline="结构") 找主图，数图上的轴线、柱、梁编号，
   和模型、依据清单对比，列出图上有、模型里没有的，和模型里有、图上找不到的。
3. 抽查：从“对得上”的里面随机挑 10 条，用 locate(page_id, bbox) 回到原图，自己读一遍数值，看是不是同一个构件。
4. 变更和缺图：notices 里改过这些图的变更单，逐条看模型是否已按它改；missing 里的图，模型是不是当成已知用了。
5. 在 Revit 里建的模型：对每张主图用 cad_file 拿 DXF，用 Revit MCP 的 compare_cad_with_model 对一遍几何（缺的、多的、偏位的、尺寸不对的）。
6. 交一份检查报告：每个问题写构件、依据、原图读到的、模型里的、建议怎么改；拿不准的写“请人工确认”，不要自己下结论。
```
