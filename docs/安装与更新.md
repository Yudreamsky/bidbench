# 安装与更新（Windows）

## 第一次安装

1. 打开发布页 <https://github.com/Yudreamsky/bidbench/releases>，下载最新的 `bidbench-setup-b数字.exe`。
2. 双击安装。安装包没有代码签名，Windows 可能提示“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。
3. 装在当前用户目录（`%LOCALAPPDATA%\Programs\bidbench`），不需要管理员权限。
   开始菜单和桌面会有“投标图纸工作台”。

要求 Windows 10 或 11（64 位）。窗口用系统自带的 Edge WebView2 显示；极少数没有 WebView2 的电脑会改用默认浏览器打开。

## 日常使用

- 第一次打开时新建项目（选一个存放位置，默认在“文档\bidbench 项目”下），以后自动打开上次的项目。
- 顶部按钮：**收图**（选压缩包、文件或整个文件夹；同一次收到的几个文件可以一起选）、**识别**（先估算花费再开始）、
  **导出**、**安全扫描**、**设置**、**切换项目**。
- 识别要用 Claude API 密钥，在“设置”里填一次即可，只保存在这台电脑上
  （`%APPDATA%\bidbench\config.json`），页面不会再显示它。

## 更新

工作台发现新版本时顶部会出现“有新版本”，点开看更新内容，点“更新并重启”：

1. 下载新的安装包，并按发布时的 SHA-256 校验，不通过就不装；
2. 窗口自动关闭，静默安装（不弹窗、不要管理员权限）；
3. 装好后自动重新打开。

项目数据、设置都不在程序目录里，更新和重装都不会动它们。新版本有问题时，更新面板里可以“回退”到上一个版本。

在国内从 GitHub 下载慢的话，在“设置 → 下载加速前缀”填一个 GitHub 下载加速地址（会加在下载地址前面）。
查询版本信息仍然直连 GitHub。

命令行也可以：`bidbench update --check`、`bidbench update`、`bidbench update --rollback`。

## 命令行和 AI 助手

安装时勾选“把 bidbench 命令加入 PATH”后，新开的命令行窗口里可以直接用 `bidbench` 命令，用法和源码版一样。
接入 Claude 桌面版、Claude Code、Codex 见 [MCP.md](MCP.md)。

## 卸载

“设置 → 应用 → 投标图纸工作台 → 卸载”。项目文件夹和 `%APPDATA%\bidbench` 里的设置不会被删除。

## 发布是怎么来的（维护者看）

- 每个 PR 都会在 GitHub Actions（`windows-installer`）里打包、跑测试、自检、试装，安装包可在该次运行的 Artifacts 里下载试用。
- 合并到 `main` 后同样打包，并发布到本仓库的 Releases，标签为 `b构建号`，发布说明是这次合并进来的 PR 标题。
- 发布用 Actions 自带的 `GITHUB_TOKEN`，不需要另配令牌。程序检查和下载更新需要仓库是公开的。
